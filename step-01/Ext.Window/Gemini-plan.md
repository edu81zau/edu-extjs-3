* title (заголовок окна).

* modal: true (модальный режим — блокировка остального интерфейса).

* plain: true (упрощенный фон тела окна, популярный стиль для диалогов).

    
2. Жизненный цикл и управление видимостью
    Разница между методами .show(), .hide() и .close().
    Параметр closeAction: подробное сравнение значений 'destroy' (уничтожение) и 
    'hide' (скрытие для повторного использования).

3. Расположение и поведение (Behavior)

<details> 

* [no_change_size](no_change_size)

Окно по умолчанию позволяет пользователю менять свои размеры, как в настольных приложениях.

resizable: false // Запрещает менять размер окна мышкой

* [without_change_position_on_the_screen](without_change_position_on_the_screen)

Окно по умолчанию позволяет пользователю менять свое положение на экране, 
как в настольных приложениях.

draggable: false // Запрещает менять положение окна на экране

</details> 

maximizable и minimizable (кнопки свертывания/разворачивания в шапке).
Ограничение области перемещения с помощью параметра renderTo или метода constrain: true

4. Начинка окна: вкладываем контент через items
    Использование свойства layout: 'fit' (когда внутренний элемент заполняет всё окно целиком).
    Добавление кнопок в массив buttons и написание обработчиков (handler) для них 
    (например, кнопки «Сохранить» и «Отмена»).
    Внутренняя начинка через xtype (панели, текстовые поля).

5. Программное управление и поиск компонентов
    Методы поиска элементов внутри окна (например, через .findById() или .findByType()).
    Работа с глобальным менеджером окон Ext.WindowMgr (или Ext.WindowManager), 
    который позволяет узнать, какое окно сейчас на переднем плане, или закрыть их все программно.

<div id="details-size">

1. Параметры width и height можно не указывать, но есть моменты:
   
    * Размеры окна будут автоматически рассчитываться на основе его содержимого (внутреннего контента).
      * Если внутри мало текста, окно подожмет свои границы ровно по размеру этого текста.
      * Если контента много, окно расширится, но может упереться в границы экрана (viewport),
        если для него не сработают ограничения.
    * Проблема: Иногда без явного указания размеров такие окна могут выглядеть сжатыми, 
      «плыть» или схлопываться в узкую полоску, если внутри нет жестко заданных элементов. 
      На практике базовые width и height для Ext.Window практически всегда прописывают, 
      чтобы гарантировать аккуратный внешний вид.

</div>

<div id="change-size">

* Программное изменение размеров window из кода
    win.setSize(500, 300); — установить новую ширину и высоту.
    win.setWidth(600); — изменить только ширину.
    win.setHeight(600); — изменить только высоту.
    win.center(); — автоматически отцентрировать окно по центру экрана 
    (вызывается именно после win.show() по одной важной технической причине: 
    расчет координат возможен только тогда, когда окно реально отрисовано в DOM-дереве браузера.).

</div>
