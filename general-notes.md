В Ext JS 3.4 handler и listeners — это два разных способа привязать реакцию (функцию-обработчик) на действия пользователя или события компонента. Главная разница между ними заключается в их назначении, универсальности и синтаксисе.
1. handler (Специализированный короткий путь)

Параметр handler создан исключительно для одного конкретного события — чаще всего для клика по кнопке (Ext.Button) или пункту меню.

    Для чего используется: Чтобы быстро и без лишней вложенности повесить действие на нажатие кнопки.

    Особенность: Он ждет одну-единственную функцию. Внутри этой функции контекст this автоматически указывает на саму кнопку.

    Пример:
    JavaScript

    {
        xtype: 'button',
        text: 'Сохранить',
        handler: function() {
            console.log('Кнопка нажата!');
            // 'this' здесь — это сама кнопка
        }
    }

2. listeners (Универсальный менеджер событий)

Параметр listeners (слушатели) — это мощный объект, который позволяет подписаться на любые события компонента (а у того же окна или текстового поля их могут быть десятки: клики, фокусы, изменение размеров, сворачивание, закрытие и т.д.).

    Для чего используется: Когда нужно отслеживать несколько разных событий компонента или настроить сложные системные события (например, жизненный цикл окна: show, hide, collapse, beforeclose).

    Особенность: Это объект, где ключи — это названия событий, а значения — функции-обработчики.

    Пример:
    JavaScript

    {
        xtype: 'window',
        title: 'Мое окно',
        listeners: {
            show: function(win) {
                console.log('Окно появилось на экране');
            },
            collapse: function(win) {
                console.log('Окно свернулось');
            },
            beforeclose: function(win) {
                // Можно вернуть false, чтобы запретить закрытие
                return confirm('Точно закрыть?');
            }
        }
    }

Интересный факт: Под капотом кнопки параметр handler просто автоматически создает точно такой же слушатель для события click через listeners. То есть handler — это просто удобное сокращение (синтаксический сахар) для кнопок.
